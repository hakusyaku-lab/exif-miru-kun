# 写真のExif見る君

写真を入れるだけで、撮影日時・カメラの機種・撮影設定（F値・シャッター速度・ISO・焦点距離）・撮影場所（位置情報）を表示する、**見るだけ**のアプリです。写真は変更しません。

- JPEG・HEIC（iPhone）・PNG・WebP・TIFF に対応
- 何枚でもまとめてドラッグ＆ドロップできます
- 位置情報があれば、Googleマップと地理院地図のリンクを表示します
- 「すべての項目を見る」で、写真に入っている Exif を全部確認できます
- 写真はブラウザの中だけで読み取ります。どこにも送信されません

## 使い方

### ブラウザで使う
`index.html` をダブルクリックしてブラウザで開き、写真をドラッグ＆ドロップします。

GitHub Pages を有効にしている場合は、そのURLからスマホでも使えます。

### Windows のデスクトップにアイコンを作る
`アイコン作成（Windows）.bat` をダブルクリックすると、デスクトップとスタートメニューに「写真のExif見る君」ができます。

## Exif が出ない写真
次のような画像は Exif が消えていることが多く、「Exif情報が見つかりませんでした」と表示されます。

- スクリーンショット
- LINE・X・Instagram などで送った／投稿したあとに保存した画像
- 一部の加工アプリで保存し直した画像

撮影した元の写真ファイルで確認してください。

## ファイル構成

```
index.html                    アプリ本体（このファイルだけで動きます）
exifr.umd.js                  Exif を読み取る部品（exifr 7.1.3）
exifr-LICENSE.txt             exifr のライセンス
icon.ico                      アイコン
アイコン作成（Windows）.bat     デスクトップにアイコンを作る
scripts/create_shortcut.ps1   上の .bat から呼ばれるスクリプト
```
